📖 О проекте

«Книжная полка» — это бесплатный инструмент для управления личной электронной библиотекой. Приложение работает как обычный HTML-файл, не требует установки, сервера или постоянного подключения к интернету. Вся библиотека хранится локально на вашем устройстве.

Главный принцип: открыл файл index.html в браузере — и всё работает. Никаких установок, регистраций, облаков. Ваши книги — только ваши.

📦 Установка и запуск

Способ 1: Самый простой

  1. Скопируйте папку book-library на компьютер
  2. Откройте файл index.html двойным кликом
  3. Всё работает!

Способ 2: На флешке

  1. Скопируйте папку book-library на USB-флешку
  2. Вставьте флешку в любой компьютер
  3. Откройте index.html — библиотека всегда с вами

📖 Как пользоваться

Добавление книг

Способ 1: Через кнопку «Добавить»

  1. Нажмите «➕ Добавить»

☁️ Облачная синхронизация (Яндекс.Диск)

Приложение поддерживает опциональную синхронизацию библиотеки между устройствами через Яндекс.Диск.

⚡ Быстрая настройка: Откройте приложение, нажмите «🔗 Подключить Яндекс.Диск» в левом меню и следуйте инструкциям.

Как это работает

  1. Вы подключаете Яндекс.Диск в настройках приложения
  2. Приложение создаёт папку book-library на вашем Яндекс.Диске
  3. Туда автоматически сохраняются library.json и прогресс чтения
  4. При открытии на другом устройстве данные загружаются из облака

Важные условия

  • Подключение облака — добровольное
  • Ответственность за использование Яндекс.Диска лежит на пользователе
  • При превышении лимита приложение предупредит и продолжит работу локально
  • Вы можете отключить облако в любой момент
⚠️ Дисклеймер: Функция облачной синхронизации предоставляется «как есть». Разработчик не несёт ответственности за любые проблемы, связанные с использованием облачного хранилища.

📲 Установка на устройство (PWA)

  1. Откройте index.html в браузере
  2. Нажмите 📲 вверху или меню браузера → «Установить приложение»

💾 Резервное копирование

  1. Нажмите «📥 JSON (бекап)» в левом меню
  2. Сохраните файл
  3. Для восстановления: «📄 JSON» → выберите файл
