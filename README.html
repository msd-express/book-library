📖 О проекте

«Книжная полка» — это бесплатный инструмент для управления личной электронной библиотекой. Приложение работает как обычный HTML-файл, не требует установки, сервера или постоянного подключения к интернету. Вся библиотека хранится локально на вашем устройстве.

Главный принцип: открыл файл index.html в браузере — и всё работает. Никаких установок, регистраций, облаков. Ваши книги — только ваши.

📦 Установка и запуск

Способ 1: Самый простой

  1. Скопируйте папку book-library на компьютер
  2. Откройте файл index.html двойным кликом
  3. Всё работает!

Способ 2: На флешке

  1. Скопируйте папку book-library на USB-флешку
  2. Вставьте флешку в любой компьютер
  3. Откройте index.html — библиотека всегда с вами

📖 Как пользоваться

Добавление книг

Способ 1: Через кнопку «Добавить»

  1. Нажмите «➕ Добавить»
  2. Нажмите «📁 Выбрать» и выберите файл книги
  3. Название и автор заполнятся автоматически (из имени файла)
  4. Выберите категорию (по умолчанию «Другое»)
  5. Добавьте теги, заметки, оценку
  6. Нажмите «💾 Сохранить»

Способ 2: Импорт с копированием

  1. Нажмите «📥 Импорт»
  2. Выберите папку с книгами
  3. Выберите папку проекта (где лежит index.html)
  4. Программа скопирует все книги в library/ и добавит в каталог

Редактирование книг

Нажмите на название книги или кнопку ✏️, измените данные и сохраните.

Поиск и фильтрация

  • Поиск: введите текст в поле поиска — результаты мгновенные
  • По тегу: кликните на тег в карточке книги
  • По категории: выберите категорию в левом меню
  • Избранное: покажет только книги с 🔖
  • Непрочитанные: покажет неотмеченные как прочитанные
  • Сброс: нажмите Escape или очистите поиск

Закладки, заметки и оценки

Отмечайте книги как избранные 🔖, добавляйте заметки и ставьте оценки от ⭐ до ⭐⭐⭐⭐⭐ при редактировании.

📂 Категории

Категории создаются автоматически на основе структуры папок в library/.

Как это работает

  1. При импорте программа копирует файлы в library/, сохраняя структуру подпапок
  2. Каждая подпапка внутри library/ становится категорией
  3. Например: library/Фантастика/Азимов/Основание.fb2 → категория Фантастика

Как создать новую категорию

Просто создайте новую папку внутри library/ через проводник (Windows) или Finder (Mac) и поместите туда книги. При следующем импорте или сканировании категория появится автоматически.

Как удалить категорию

Нажмите ✕ рядом с категорией в левом меню. Все книги из этой категории будут перенесены в «Другое». Сами файлы на диске останутся нетронутыми.

Категорию «Другое» удалить нельзя — она служит для книг, у которых не определилась категория.

📥 Импорт книг

Библиотека поддерживает импорт книг с автоматическим копированием в папку library/.

Как это работает

  1. Нажмите «📥 Импорт»
  2. Выберите исходную папку с книгами
  3. Выберите папку проекта (где лежит index.html)
  4. Программа скопирует все найденные книги в library/
  5. ZIP-архивы будут автоматически распакованы
  6. Все книги добавятся в каталог

💾 Резервное копирование

Автоматически

При каждом сохранении создаётся бекап в localStorage браузера (последние 5 версий).

Вручную

  1. Нажмите «📥 JSON (бекап)» в левом меню
  2. Сохраните файл в надёжное место
  3. Для восстановления: «📄 JSON» → выберите файл
Рекомендуется делать ручной экспорт раз в месяц.
